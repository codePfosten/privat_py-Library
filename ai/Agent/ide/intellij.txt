IntelliJ AI Prompts

Short, reusable prompts for IntelliJ AI and inline code assistance.

Documentation

Document this code in clear, concise English. Explain its purpose, important behavior, parameters, return value, and relevant exceptions. Do not change the code.

JavaDoc

Add concise JavaDoc to this method/class. Document purpose, parameters, return value, exceptions, and important behavior. Do not change the implementation.

README

Create or improve the README for this project in clear, professional English. Cover purpose, features, requirements, setup, usage, and relevant configuration. Only describe functionality that actually exists.

Explain Code

Explain this code simply. Describe what it does, how the main components interact, and important assumptions. Do not modify the code.

Improve Naming

Review the naming in this code and suggest clearer names for classes, methods, variables, and constants. Do not change anything automatically.

Add Comments

Add only useful comments where the code’s intent is not obvious. Do not comment obvious operations or restate the code. Do not change functionality.

Refactoring Suggestions

Analyze this code for refactoring opportunities that improve readability or maintainability. Do not modify the code. Explain each suggestion briefly.

Generate Test Cases

Suggest meaningful test cases for this code. Focus on observable behavior, edge cases, invalid input, and important boundaries. Do not implement the tests.

Find Issues

Review this code for likely bugs, incorrect assumptions, and missing error handling. Report concrete or plausible issues only. Do not modify the code.

Improve Documentation

Improve the existing documentation for clarity, correctness, and consistency. Keep it concise and do not change the code.

Simplify Code

Identify unnecessarily complex parts of this code and suggest simpler alternatives. Do not modify the code.

Explain Error

Explain the cause of this error, identify the relevant part of the code, and suggest how it could be fixed. Do not modify the code.

Review Method

Review this method for correctness, readability, and maintainability. Report issues and suggestions only. Do not modify the code.

Review Class

Review this class for responsibility, cohesion, coupling, readability, and maintainability. Report issues and suggestions only. Do not modify the code.

Create Commit Message

Based on the current changes, suggest a concise Git commit message. Describe only changes that actually exist.

Create PR Description

Based on the current changes, create a concise pull request description in English. Include the purpose, important changes, and tests actually performed. Do not invent information.
